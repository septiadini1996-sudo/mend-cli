mend is one command-line tool that applies AI-written edits in all four formats models use — unified diffs (with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of text files, exactly as the competition's SPEC.md specifies: three-tier line matching that tolerates drifted whitespace and indentation, and every file changed or none.

## Run it

```sh
node main.ts [options] [PATCH]
```
